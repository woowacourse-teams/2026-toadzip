# 기존 임시 작업 자료

로고 비교 시안과 이전 자산 등 기존 로컬 작업 자료의 보관 위치다. 저장소에는 이 안내만 포함하며 자료는 로컬 보관 상태에 따라 없을 수 있다.

새 개인 작업 자료는 저장소 루트의 `.local/`에 보관한다. 기존 `tmp/` 자료는 소유자의 명시적인 요청 없이 이동하거나 삭제하지 않는다.
