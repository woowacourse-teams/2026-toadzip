# 임시 작업 자료

로고를 비교하거나 이전 자산을 보관할 때 사용한 로컬 작업 자료를 모아 둡니다.
저장소에는 이 안내만 포함하며, 아래 자료는 로컬 보관 상태에 따라 없을 수 있습니다.

## 디렉터리·주요 파일

| 경로 | 역할 |
| --- | --- |
| `brand-assets/` | 로고·아이콘·공유 이미지 제작 스크립트와 자산 묶음을 보관합니다. |
| `brand-assets/generate.mjs` | BOK 로고·두꺼비 아이콘의 SVG·PNG 시안을 생성할 때 사용한 스크립트입니다. |
| `brand-assets/build-social-card.mjs` | 링크 공유 미리보기 이미지를 만들 때 사용한 스크립트입니다. |
| `brand-assets/refresh-package.mjs` | 로고 PNG와 자산 비교용 미리보기 이미지를 갱신하는 스크립트입니다. |
| `brand-assets/bok-brand-assets.zip` | 제작한 브랜드 자산을 묶어 보관한 압축 파일입니다. |
| `frontend/public/logo-variants/` | 이전 프론트엔드 정적 자산에서 옮겨 둔 로고 변형안과 비교 이미지를 보관합니다. |
| `logo-concepts-250*.html` | 로고 초기안, `bok` 변형과 후보를 브라우저에서 비교하는 HTML 시안입니다. |

서비스에 사용하는 정식 자산은 [frontend/public/](../frontend/public/),
자산 사용 기준은 [브랜드 자산 안내](../frontend/docs/brand-assets.md)를 참고합니다.
