# 알림함과 웹 푸시 화면

서버의 대상 선정·중복·전달 계약은 [알림 생성·전달](delivery.md), 관심 대상 신청·해제는 [알림 설정](settings.md)을 따른다.

아래 코드·빌드 경로는 `frontend/` 기준이다. Docker 빌드의 `.env`는 저장소 루트를 기준으로 한다.

공개 탐색·알림함·알림 관리 경로는 하나의 알림 Provider를 공유한다. 회원·visible·online인 동안 60초마다 개수만 조회하고 로그인·탭 복귀·FCM 수신 때 갱신한다. 알림함 GET은 읽음으로 바꾸지 않는다.
푸시를 거부하거나 지원하지 않는 환경에서도 보관함을 이용할 수 있다.

`.env.example`의 공개 Firebase 설정과 `VITE_NOTIFICATION_PUSH_ENABLED`를 사용한다. 기본 false이며 미설정 시 권한 팝업을 띄우지 않는다.
비공개 Firebase 키는 브라우저에 넣지 않는다. 권한은 설정의 명시적 버튼에서만 요청한다.
끄기·로그아웃은 서버 기기 바인딩을 해제한다. 탭·계정이 공유하는 Firebase 설치는 삭제하지 않으며, 서버 로그아웃 성공 즉시 화면 상태를 비운다.
로컬 Vite는 `frontend/.env`, Docker 빌드는 루트 `.env`의 웹 푸시 공개 설정을 사용한다. Docker 설정 변경 후에는 frontend 이미지를 다시 빌드한다.
SDK는 13.0.0의 register/onRegistered(FID)를 사용하며 기존 registration token API를 사용하지 않는다.

`npm run dev`는 worker를 `.worker-dev/`에 먼저 빌드하고 개발 서버에서 같은 origin의 `/firebase-messaging-sw.js`로 제공한다.
worker 코드·환경 변수를 수정하면 개발 서버를 재시작한다. production build는 앱 후 worker를 IIFE 단일 파일로 생성한다.
Nginx는 worker를 JavaScript MIME/no-cache로 제공하고 파일이 없으면 404를 반환한다.
manifest는 기존 브랜드 아이콘의 192px·512px PNG를 제공한다. iPhone/iPad는 iOS 16.4 이상·홈 화면 설치가 필요하다.

## 모바일 홈 화면 추가 안내

767px 이하 화면에서 홈의 소개 영역과 탐색 지도의 설치 카드를 로그인·알림 신청 전에도 보여준다. 지도에서는 검색·목록·상세·거리뷰를 보는 동안 카드를 숨긴다. 닫기는 현재 방문에서만 적용하며 새로고침하거나 새로 접속하면 다시 표시한다. 같은 방문 중 화면을 이동해도 닫기 상태를 유지한다. 닫기 상태는 브라우저 저장소에 기록하지 않으며, 이전 버전의 하루 숨김 기록도 적용하지 않는다. 홈 하단·회원 메뉴·알림 설정의 설치 진입점으로 안내를 다시 열 수 있다.

지원 브라우저의 `beforeinstallprompt`를 보관해 사용자 클릭에서만 설치 확인창을 연다. Android에서 이벤트가 준비되면 카드·메뉴의 버튼은 ‘복덕방 설치하기’로 표시하며, 사진 안내 없이 브라우저 설치 확인창을 바로 연다. 안내를 보는 중 이벤트가 도착해도 안내 안에 직접 설치 버튼을 제공한다. 최종 설치는 사용자가 브라우저 확인창에서 승인해야 한다. 이벤트가 없거나 호출이 실패하면 기기별 실제 캡처 안내를 연다. 설치 취소를 완료로 표시하지 않으며, `appinstalled` 또는 standalone 실행이 확인되면 설치 진입점을 숨긴다. 다른 브라우저에서 설치했거나 iOS의 일반 Safari로 재방문한 경우 설치 여부를 확정할 수 없어 다시 안내할 수 있다.

기기 선택 탭 없이 현재 기기에 맞는 안내만 보여준다. 직접 설치를 사용할 수 없는 Android의 사진 안내는 유지한다. 아이폰은 Safari 공유 → 홈 화면에 추가 → 추가, 안드로이드는 Chrome 더 보기 → 홈 화면에 추가 → 설치 확인을 세 단계로 안내한다. 한국어 복덕방 실제 캡처의 환경은 안내 아래와 [자산 설명](../../../frontend/public/install/README.md)에 표시한다. 앱 내 브라우저에서는 현재 주소를 복사해 Safari·Chrome에서 여는 방법을 제공한다. 주소는 저장하거나 분석에 보내지 않는다.

설치와 알림 권한은 별개다. Android 알림에 설치를 강제하지 않으며, iPhone 설치 안내는 기존 기기 알림 흐름에서도 재사용한다. 설치 버튼에서 알림 권한을 요청하거나 관심 대상을 변경하지 않는다. 설치 후 같은 계정으로 로그인하면 기존 서버의 관심 대상이 유지되고, 기기 알림은 별도로 켠다. 768px 이상에서는 새 설치 카드·메뉴·캡처 안내를 노출하지 않고 기존 알림 도움말을 유지한다.

실제 프로젝트의 권한·전경·배경·페이지 종료·기기 2대·계정 교체·배포 후 worker 갱신 검증은 별도로 필요하다.
[서버 운영·검증 범위](delivery.md)를 따른다.
