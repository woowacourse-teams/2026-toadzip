# 알림 기능

회원의 관심 대상 설정부터 새 공고·신청 일정 알림 생성, 전달과 화면 확인까지의 계약을 설명한다.

## 문서 안내

| 문서 | 다루는 내용 |
|---|---|
| [회원 설정](settings.md) | 신청·해제·현재 상태, 저장·보유와 분석의 경계 |
| [생성·전달](delivery.md) | 대상 선정·중복 방지·알림함·FCM·재시도와 전달 보장의 한계 |
| [알림함·웹 푸시](ui.md) | 사용자 화면, 공개 Firebase 설정·worker 빌드와 브라우저 검증 |

## 관련 문서

관리자 신청 현황은 [관리자 알림 조회](../admin/notifications.md), 실제 플래그·스키마·보관 점검은 [알림 운영](../../operations/notifications.md)을 따른다.
