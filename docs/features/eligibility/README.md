# 공고 신청자격 판정

사용자 정보에 따른 공고별 신청자격 판정과 근거 제공을 설명한다. 공고 구조화부터 사용자 입력,
판정 결과와 갱신까지 연결하며 이전 기본 비교 API는 별도 호환 계약으로 다룬다.
