# 사용자 의견 접수

- 의견 보내기는 탐색·마이페이지 위의 모달로 연다. 닫기와 Escape는 원래 화면으로 돌아간다. 데스크톱은 배경 클릭으로도 닫히며 모바일은 배경 클릭으로 닫히지 않는다. `/feedback` 직접 접근도 지원한다.
- 탐색 화면에 머문 뒤 1분이 지나면 왼쪽에 작은 의견 요청을 띄운다. 안내를 닫거나 선택하거나 제출하면 같은 브라우저 세션에서 다시 띄우지 않는다. 숨은 탭에는 새 안내를 띄우지 않는다.
- `POST /api/v1/feedback`: 로그인 없이 `{ "surveyAnswer": "VERY_DISAPPOINTED", "content": "의견 내용" }` 제출
- 설문 답변은 필수 단일 선택이다. `VERY_DISAPPOINTED`(매우 실망), `SOMEWHAT_DISAPPOINTED`(약간 실망), `NOT_DISAPPOINTED`(실망하지 않음), `NO_LONGER_USING`(더 이상 쓰지 않음)을 받는다. 누락·알 수 없는 값은 `400`으로 거절한다.
- `GET /api/auth/csrf`에서 받은 토큰을 요청 헤더에 전달한다. 기존 CSRF 보호를 유지한다.
- 의견 내용은 선택이며 UTF-16 기준 최대 2,000자다. 누락·null은 빈 문자열로 저장한다. 양끝 공백을 제거하고 내부 줄바꿈은 보존한다.
- NBSP·좁은 NBSP·BOM을 포함한 양끝 공백도 제거하며 공백만 담긴 선택 의견은 빈 문자열로 저장한다.
- 성공은 `201`과 `{ "data": { "id": 1 } }`, 검증 실패는 기존 `VALIDATION_FAILED` 오류 계약이다.
- 설문 답변, 본문과 UTC 접수 시각을 저장한다. 회원 ID, 이메일, IP, 화면 URL을 별도로 수집하지 않는다.
- 공개 조회 API는 제공하지 않는다. 화면에서는 개인정보 입력을 피하도록 안내한다.

## 배포와 복구

- `V20261007_01__create_feedback.sql`은 새 테이블과 최신순 조회 인덱스만 추가한다.
- Flyway 적용 후 Hibernate validate와 애플리케이션 시작이 진행된다.
- `V20261104_05__feedback_survey.sql`은 nullable `survey_answer` 컬럼을 추가하고 빈 본문 제약을 설문 또는 본문이 있는 조건으로 교체한다. 기존 의견의 설문은 `NULL`로 보존하며 관리자 화면은 ‘미응답’으로 표시한다.
- 마이그레이션 → 백엔드 → 프론트엔드 순서로 배포한다. 구 프론트엔드는 설문을 보내지 않아 새 백엔드에서 `400`으로 거절되므로 전환 중 구 화면은 새로고침해야 한다.
- 이전 서버는 본문이 있는 기존 방식의 제출을 저장할 수 있다. 설문만 제출하는 새 화면은 이전 서버의 본문 필수 검증과 호환되지 않으므로 서버 복구 시 프론트엔드도 함께 복구한다. 수집한 설문·의견과 컬럼은 보존한다.
- 운영 DB에 수동 SQL을 실행하거나 접수된 의견을 삭제하는 작업은 이번 구현 범위에 포함하지 않는다.

## 관리자 조회

- `GET /api/admin/feedback?keyword=검색&page=0&size=20`은 ADMIN 세션만 접근할 수 있다.
- 검색어는 최대 200자, page는 0 이상, size는 1~100이며 기본값은 20이다.
- 본문을 대소문자 구분 없이 검색한다. `%`, `_`, `!`는 와일드카드가 아닌 입력 문자로 취급한다.
- `createdAt DESC, id DESC`로 정렬한다. `createdAt`은 UTC ISO 8601 시각이며 관리자 화면은 한국 시각으로 표시한다.
- 응답은 `data` 안에 `items`, `page`, `hasNext`, `totalElements`, `totalPages`를 포함한다.
- 각 항목은 `id`, 전체 `content`, `surveyAnswer`, `createdAt`과 기존 처리 기록을 포함한다. 설문 답변은 목록·상세·처리 저장 응답에 포함되며 처리 기록 수정으로 바뀌지 않는다. 범위 밖 페이지도 전체 검색 건수를 보존한다.
- 검색 건수를 먼저 확인하므로 매우 큰 범위 밖 페이지도 JPA offset 제한에 걸리지 않고 빈 목록을 반환한다.
