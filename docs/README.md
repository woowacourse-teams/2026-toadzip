# 공용 문서

사람과 AI가 함께 사용하는 기술 문서의 시작점이다. 설치·개발·기능·운영 중 하려는 작업에 맞는 폴더에서 문서를 찾는다.

## 문서 안내

| 문서 | 다루는 내용 |
|---|---|
| [환경 설정](setup/README.md) | 로컬·개발·운영 환경 준비와 최초 실행 |
| [개발 기준](development/README.md) | 구현·API·테스트·디자인·문서 작성 기준 |
| [기능 명세](features/README.md) | 현재 기능의 사용 흐름·계약·정책·실패 조건 |
| [운영](operations/README.md) | 배포·모니터링·데이터 점검과 복구 절차 |
| [예시 입력](fixtures/README.md) | 공고 JSON 가져오기의 입력 예시와 사용 범위 |
| [점검 SQL](queries/README.md) | 알림 데이터·스키마 확인용 쿼리와 실행 조건 |

## 관련 문서

문서 추가·수정은 [문서 작성·관리 규칙](development/documentation.md)을 따른다. 서비스 목적은 [서비스 소개](../SERVICE_OVERVIEW.md), 기여 절차는 [기여 가이드](../CONTRIBUTING.md), AI 작업 지침은 [AGENTS](../AGENTS.md)에서 확인한다.
