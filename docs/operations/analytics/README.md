# 제품 분석

사용자 행동을 GA4·PostHog에서 측정·분석하는 설정, 이벤트·지표와 수집 확인 방법을 설명한다.

## 문서 안내

| 문서 | 다루는 내용 |
|---|---|
| [GA4](ga4.md) | 환경별 측정 연결, 탐색 이벤트·지표와 콘솔·DebugView 확인 |
| [PostHog](posthog.md) | 제품 이벤트·브라우저 식별·핵심 지표·대시보드 SQL과 수신 검증 |

## 관련 문서

동의·철회·SDK 수집 경계는 [개인정보 기능](../../features/privacy/README.md)을 따른다. 로컬 코드 검증과 외부 도구의 실제 수신 확인은 구분한다.
