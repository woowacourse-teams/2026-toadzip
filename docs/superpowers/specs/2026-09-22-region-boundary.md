# 지역 검색 경계 표시

시군구 검색 결과를 선택하면 공식 경계를 표시하고 해당 지역 전체가 보이도록 지도 범위를 맞춘다. 테두리는 D-day 빨강 #D34F3E, 실선 2px, 불투명도 1이며 내부는 같은 색 불투명도 0.08이다. 섬과 내부 구멍을 보존하고 경계는 클릭을 가로채지 않는다.

공식 원본을 개발 시 한 번 받아 지역별 GeoJSON과 가벼운 지역 코드·이름·bbox 인덱스를 생성한다. 사용자 브라우저는 우리 서비스의 정적 파일만 조회하고 HTTP 캐시와 제한된 메모리 캐시를 사용한다. 원본 출처, 수집일, 파일 해시, 좌표계, 라이선스를 기록하며 확인되지 않은 데이터 기준일이나 코드 대응을 만들어내지 않는다.

인덱스로 즉시 fitBounds하고 비동기 GeoJSON 응답은 도형만 갱신한다. 지도 이동·확대축소, 검색창 닫기, 필터 변경, 마커 선택은 경계를 유지한다. 다른 지역 검색은 교체한다. 검색 지역 칩에서 지역 다시 보기와 표시 해제를 제공한다. 해제는 카메라와 필터를 바꾸지 않는다. 실패 시 경계를 가져오지 못했다는 안내와 재시도를 제공하고 기존 검색은 동작한다. 주택 지역 필터와 경계 선택은 별개이며 URL의 boundaryRegionCode로 선택을 복원한다.

브랜치 feat/181-region-boundary에서만 변경한다. 원본 다운로드 완료와 지역 코드 검증 전에는 임의 도형을 제품 데이터로 넣지 않는다.
