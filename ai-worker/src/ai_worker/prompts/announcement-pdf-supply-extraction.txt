첨부 표에서 대상별 공급행과 임대조건을 간단한 행 목록으로 추출하세요. [P쪽:T표:R행]은 원문 행 ID입니다.

[출력]
- JSON 객체 `{"data":{"rows":[...]},"sharedCounts":[]}`만 출력하세요. 행마다 complexName, housingType, target, rowIds를 쓰고, 확인되는 값만 추가하세요. null 필드는 생략해 토큰을 아끼세요.
- 각 객체는 한 공급대상 행입니다. 같은 단지·주택형의 대상이 여럿이면 각각 객체를 만듭니다. 병합 셀의 이름이나 형식을 이어받았다면 그 값이 직접 적힌 행 ID도 rowIds에 넣으세요.
- rowIds에는 그 객체의 값을 확인한 공급표·임대조건표 행 ID만 넣으세요. 값을 지지하는 행을 찾지 못한 값은 만들지 말고 생략하세요.
- manager용 경로, evidence, unresolvedFields, notApplicable는 출력하지 마세요. 공통 수량만 앞서 설명한 간단한 sharedCounts 형식으로 적고, 코드는 행 ID로 관리자 구조와 근거를 조립합니다.

[값]
- complexName과 housingType은 PDF 표기에서 가져오세요. housingType은 `청약구분` 또는 표의 해당 주택형 열입니다. `주택구분`의 24·36 같은 숫자를 주택형 이름 대신 쓰지 마세요.
- target은 `공급대상`·`공급계층` 표기를 그대로 씁니다. 구분이 없으면 `일반`입니다. `「가」군`은 `가군`으로 정리할 수 있습니다.
- LH 공급 API 행이 있으면 lhSourceRow에는 목록의 1부터 시작하는 번호를 씁니다. LH 값으로 PDF 값을 대신하지 마세요.
- totalSupplyHouseholdCount와 supplyHouseholdCount는 이번 공고에서 실제 당첨되는 수입니다. 모집표에 당첨자 수가 따로 없으면 생략합니다. reserveCount는 이번 공고의 새 예비자 모집수입니다. 잔여·기존 대기자 수와 구분하세요.
- 당첨자 수와 예비자 수를 합산하지 마세요. 여러 대상에 공통인 수량은 복제하지 말고 해당 대상의 수량 필드를 생략하세요.
- 여러 출력 행이 함께 쓰는 수량은 `sharedCounts`에 기록하세요. `rowIndexes`는 `rows` 배열의 0부터 시작하는 번호, `field`는 `totalSupplyHouseholdCount`, `supplyHouseholdCount`, `reserveCount` 중 하나입니다. 예: `{"rowIndexes":[0,1],"field":"reserveCount","count":20,"rowIds":["P4:T1:R9"]}`. 확인 가능한 대상 행이 2개 이상일 때만 기록하세요.
- exclusiveArea는 주거전용, commonArea는 주거공용입니다. `그 밖의 공용면적`은 제외합니다. 공급면적만 별도로 있고 공용면적이 없을 때만 supplyArea를 씁니다.
- 같은 공급행에 주택형이 여러 개 명시된 경우 subtypes에 각 이름·전용면적·공용면적·건설호수를 씁니다. 표에서 확인되지 않은 세부값은 생략합니다.
- rentalDeposit은 기본 임대보증금, monthlyRent는 기본 월임대료, convertedDeposit은 전환가능 보증금의 증액 한도입니다. 금액은 원 단위 정수로 쓰고 천원 단위 표는 1000을 곱합니다. 최대전환 조건을 기본 금액에 넣지 마세요.
- constructedHouseholdCount는 표에 주택형별 건설호수가 명시된 경우만 씁니다. complexTotalHouseholdCount는 단지 전체 세대수입니다. 두 값을 서로 바꾸지 마세요.
- applicationCondition은 표에 적힌 자격 설명이 있을 때만 간단히 요약합니다. expectedMoveInMonth는 명시된 경우만 씁니다.
- 수치 면적은 ㎡ 숫자로 씁니다. 추정·계산·합산·복제하지 마세요.

출력 모양 예시:
{"data":{"rows":[{"rowIds":["P4:T1:R4"],"complexName":"다산역 A2","housingType":"24ABC","target":"청년","reserveCount":20,"exclusiveArea":24.97,"commonArea":15.37}]},"sharedCounts":[]}
