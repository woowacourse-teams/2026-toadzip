# 홈 화면 추가 안내 캡처

모든 이미지는 로컬 복덕방 페이지를 한국어 브라우저에서 직접 캡처한 원본 PNG다. 안내에서는 CSS로 필요한 메뉴 영역을 확대 표시한다.

| 파일 | 캡처 환경과 내용 |
| --- | --- |
| `iphone-share.png` | iPhone 17 / iOS 26.0 Simulator, Safari 더 보기의 공유 메뉴 |
| `iphone-home.png` | 같은 기기의 공유 → 더 보기 → 홈 화면에 추가 |
| `iphone-add.png` | 같은 기기의 복덕방 추가 확인창, 웹 앱으로 열기 활성화 |
| `android-browser.png` | Android 15 (API 35) Emulator, 한국어 Chrome 주소창 더 보기 |
| `android-menu.png` | 같은 기기의 홈 화면에 추가 메뉴 |
| `android-add.png` | 같은 기기의 복덕방 앱 설치 확인창 |

2026-10-26 캡처. localhost 주소는 로컬 개발 환경이다. 기기·OS·브라우저 버전에 따라 메뉴 위치와 명칭은 달라질 수 있다. 확인창 캡처는 설치 완료나 푸시 수신 검증을 의미하지 않는다.
