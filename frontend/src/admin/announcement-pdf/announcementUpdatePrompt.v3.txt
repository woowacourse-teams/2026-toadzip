첨부한 공식 공고문 PDF에서 아래 항목을 추출해 주세요. 이미 등록된 공고를 관리 화면에서 보정하는 데 씁니다.

[응답 형식]
설명이나 마크다운 코드 블록 없이 JSON 객체 하나만 반환하세요. 문자열 안에서도 \~ 같은 마크다운 이스케이프를 쓰지 마세요.
{
  "data": { 추출한 값 },
  "sharedCounts": [ 여러 공급행이 함께 쓰는 모집수 ],
  "notApplicable": [ 이 공고에 해당하지 않는 항목 ],
  "evidence": [ 값의 근거 ]
}
아래 [응답 예제]에 있는 필드만 쓰세요. 예제에 없는 필드는 만들지 마세요.

[값 작성 규칙]
- 공고문에서 확인한 값만 쓰세요. 추정하지 마세요.
- 값을 확인하지 못했으면 null로 두고 data.unresolvedFields에 path와 reason을 적으세요.
- 이 공고에 원래 없는 항목(예: 선착순이라 순위가 없음, 입주예정월을 안내하지 않음)은 null로 두고 unresolvedFields가 아니라 notApplicable에 path와 reason을 적으세요.
- 금액은 원 단위 정수입니다. 쉼표·만원 표기를 쓰지 말고, "천원" 단위 표는 1,000을 곱하세요.
- 날짜는 YYYY-MM-DD, 연월은 YYYY-MM, 일시는 YYYY-MM-DDTHH:mm:ss입니다.

[접수처]
- receptionPlace.method는 다음 중 하나입니다. ONLINE(인터넷·모바일), VISIT(현장 방문), MAIL(우편), ETC(그 밖의 방법).
- 인터넷과 현장 접수를 함께 받으면 공고문이 주된 방법으로 안내한 것을 쓰고, 판단할 수 없으면 null과 이유를 적으세요.

[일정]
- schedules[].scheduleType은 다음 중 하나입니다. APPLICATION(신청 접수), DOCUMENT_SUBMISSION(서류 제출), WINNER_ANNOUNCEMENT(당첨자·예비입주자 발표), CONTRACT(계약), MOVE_IN(입주), ETC(그 밖의 일정, 예: 서류제출 대상자 발표).
- 공고문 일정표의 일정마다 하나씩 쓰세요. 단지별로 같은 일정이면 한 번만 쓰세요.
- 한 시점만 있는 일정(예: "16:00 이후" 발표)은 endAt을 startAt과 같게 쓰세요.
- 시각을 안내하지 않은 일정은 00:00:00으로 쓰세요.

[공급행]
- 공급행은 공고문 공급 표의 (단지, 주택형) 한 행입니다.
- complexReference.sourceComplexName은 공고문의 단지명, sourceHousingTypeName은 공고문의 주택형 표기를 그대로 쓰세요.
- 대학생·청년·신혼부부 같은 공급대상은 주택형명에 넣지 말고 targets로 나누세요. 같은 공급대상이 소득 구간으로 나뉘면 target에 구간까지 쓰세요(예: "청년 소득(×)").
- 공급대상 구분이 없으면 target을 "일반"으로 쓰세요.
- totalSupplyHouseholdCount는 이번에 모집하는 호수(예비자 모집이면 모집할 예비자수)입니다. 건설호수·대기 중인 예비자수와 구분하세요.
- 여러 공급행이 하나로 묶인 모집수는 각 행에 복제하거나 나누지 마세요. 해당 행의 값은 null로 두고 sharedCounts에 묶인 행의 path와 수를 적으세요.
- exclusiveArea는 주거전용면적, supplyArea는 주거전용면적 + 주거공용면적입니다. 공고문에 적힌 자릿수 그대로 ㎡ 소수로 쓰세요.
- constructedHouseholdCount는 공급 표에 적힌 해당 주택형의 건설호수입니다. 단지 전체 건설호수나 모집호수와 구분하고, 주택형별 건설호수가 없으면 null로 두세요.
- targets의 rentalDeposit은 임대보증금 계, monthlyRent는 월임대료입니다.
- convertedDeposit은 "전환가능 보증금 한도액" 중 (+) 증액 한도입니다. 최대전환 시 보증금이나 (-) 감액 한도를 쓰지 마세요.
- 대상별 모집수가 표에 없으면 supplyHouseholdCount는 null로 두고 notApplicable에 적으세요.

[evidence]
- 값을 채운 data 항목마다 하나 적으세요. 공급행은 행마다 하나, 대상은 대상마다 하나입니다.
- page는 PDF 뷰어 기준 1부터 시작하는 쪽 번호입니다.
- quote는 원문에서 그대로 복사한 40자 이내 문구입니다. 표의 값이면 그 값의 숫자가 들어간 부분을 고르세요.
