# 관리자 작업공간

관리자 기본 진입은 `검토할 데이터`다. 왼쪽 메뉴의 매일 하는 작업에서 검토·단지·공고·누락 대조를 연다.
수집·원천 도구와 회원·알림 메뉴는 펼쳐서 사용하며, 해당 경로로 직접 접근하면 소속 그룹이 열린다.
모바일에서는 `메뉴`로 탐색을 열고 Escape 또는 다른 페이지 이동으로 닫는다.

## 데이터를 확인하고 수정하기

- 검토 작업실: `검토 대상`과 `내 담당 업무`를 분리한다. 빠른 조건·이름·대상·사유 필터는 URL에 남는다.
- 목록의 결과 수는 현재 검색 조건의 총 개수다. 현재 페이지 항목으로 전체 통계를 추정하지 않는다.
- 단지·공고 일반 상세는 읽기로 진입한다. `수정`으로 입력을 열고 저장·취소 후 읽기로 돌아온다.
- `데이터 검증`은 공식 원천 비교, `PDF로 보완`은 파일 근거 작업, `담당 업무`는 배정·기한·업무 상태다.
- `section=verification`, `documents`, `tasks` 등 상세 링크의 작업 위치를 직접 열 수 있다.
- 업무 완료와 데이터 검증 완료는 별개다. 충돌·미저장 입력 보호와 원천 확인 기준은 유지한다.

## PDF 보완

`자료 선택` → `근거·수정안` → `확인·저장`으로 진행한다. 아직 준비되지 않은 단계는 열리지 않는다.
단계를 바꾸는 동작은 기존 입력을 지우지 않는다. 새 파일·대상·쪽수 선택은 기존 검토 결과를 무효화한다.
보관·복원은 보조 영역에 두고, 에이전트 도구는 해당 작성 방식을 선택했을 때 표시한다.
최종 확인에서는 항목 선택·공식 URL·확인 메모가 있어야 저장할 수 있다.

디자인은 기존 사용자용 화면의 토큰·Button을 사용한다. 관리자 스타일은 관리자 영역에만 적용한다.
