# 지역 경계 데이터

## 선정한 공식 원본

- 데이터: 국토교통부/K-Geo플랫폼 **법정구역정보**
- 출처: https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=NA&dsId=21
- 선택 대상: 전국 SHP 전체데이터, 기준일 2026-09-09, 갱신일 2026-09-09, 페이지 표기 약 120MB.
- 제공 범위: 법정동(시군구·읍면동·리 단위) 경계도면. 실제 SHP 속성과 도형은 다운로드 후 검증한다.
- 공개 좌표계: GRS80 / EPSG:5186. 변환 시 원본 .prj와 대조하며 페이지의 과거 생산 좌표계 설명(Bessel)과 혼동하지 않는다.
- 제공 주기: 전체 월간, 변동 일간. 이 기능은 검증한 전체 스냅샷을 배포하므로 실시간 경계를 보장하지 않는다.
- 라이선스: [CC BY 2.0 KR](https://creativecommons.org/licenses/by/2.0/kr/). 배포 데이터와 UI에 원저작자/출처를 표시하고 가공 여부를 기록한다.

## 연속수치지형도 대신 법정구역정보를 선택한 이유

[행정경계(시군구) 공식 페이지](https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=MK&dsId=30252)의 2026-09-16 운영기관 답변에 따르면 당시 검수 중인 연속수치지형도는 2025년 기준이고, 전남광주·인천 개편 반영본은 2027년 수급 예정이다. 같은 답변이 최신 개편에는 법정구역정보 데이터셋을 이용하도록 안내한다. 따라서 페이지 갱신일만 보고 N3A_G0100000.zip을 최신 행정구역 경계로 취급하지 않는다.

## 배포 전 검증

원본 파일 확보 후 아래 증거를 생성한다. 현재 원본 파일이 저장되지 않아 데이터 파일과 인덱스는 아직 생성하지 않았다.

1. 원본 ZIP의 SHA-256, 다운로드 시각, 기준일/갱신일을 별도로 기록한다.
2. 실제 SHP/DBF/PRJ의 형식·코드·좌표계와 빈 도형/잘못된 도형을 확인한다.
3. backend/src/main/resources/region/regions.csv와 코드 및 이름을 비교한다. 과거 코드 별칭만을 근거로 달라진 경계를 같은 것으로 간주하지 않는다.
4. 수원·부천 등 부모 도시는 검증된 자식 구 경계를 합쳐 내부 경계선을 제거한다. 떨어진 섬과 도형의 내부 구멍은 보존한다.
5. WGS84 경위도 좌표로 변환하고 각 지역 bbox와 좌표 범위, 도형 유효성, 누락 코드, 파일 크기를 검사한다.
6. 단순화한다면 허용 오차와 최대 경계 이동·면적 변화를 원본에 대해 측정한다. 서비스 지도 표시용이며 법적 경계 확정 자료로 사용하지 않는다.

## 제공 방식

검증된 지역별 GeoJSON을 `/region-boundaries/<version>/<regionCode>.geojson`에 배포한다. 버전은 원본과 가공 결과를 구별해야 하며 같은 경로의 내용을 덮어쓰지 않는다. 기존 페이지가 참조하는 이전 버전 파일은 새 배포 직후 제거하지 않는다.

앱에는 가벼운 지역 이름·코드·bbox 인덱스만 포함한다. 검색 선택 시 인덱스로 지도 범위를 즉시 맞추고 상세 경계 파일은 비동기로 받는다. 상세 파일 응답은 카메라를 움직이지 않는다. 우리 정적 서버만 조회하므로 VWorld API 키는 필요 없다.

성공한 정적 파일은 HTTP 캐시를 사용한다. 메모리에는 최근 검증에 성공한 8개 지역만 보관하고 실패/취소 응답은 저장하지 않는다. 캐시는 브라우저가 삭제할 수 있으므로 서버 원본 파일이 항상 필요하다. 없는 경계 파일은 SPA HTML 대신 404로 응답한다.
