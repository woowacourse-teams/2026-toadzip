# 검토 담당자·기한·알림

검토 목록과 단지·공고 상세의 **업무 담당·기한 관리**에서 기존 업무를 조회한 뒤 담당자, 기한,
상태와 메모를 저장한다. 빈 담당자는 미배정이고, 기한 없는 업무도 보관할 수 있다.
업무 완료는 실제 데이터 검증과 별개다. 공식 근거 확인과 값 수정은 기존 비교 화면에서 진행한다.

검토 목록의 **담당 업무·기한 알림**은 내 담당 업무를 기본으로 보여준다. 전체 담당자,
상태, 기한 초과 조건으로 좁힐 수 있고 상세 비교 화면으로 이동할 수 있다.
내 담당 알림은 미완료 업무의 기한 초과와 확인한 원천 변경·소실을 표시한다.
기한은 한국 날짜이며 당일은 초과로 처리하지 않는다. 최초 원천 확인 전에는 변경을 감지하지 않는다.

화면을 보는 동안 알림 수를 1분마다 갱신한다. 새로고침 버튼으로 목록도 갱신할 수 있다.
이메일·메신저·브라우저 푸시는 전송하지 않는다.
조회 실패는 빈 목록으로 표시하지 않는다. 저장 충돌에서는 입력을 보존하고 저장을 잠근다.
최신 업무를 조회하면 서버의 기존 업무와 현재 입력을 비교한 뒤 다시 저장할 수 있다.

API 계약은 [백엔드 문서](../../backend/docs/admin-review-tasks.md)에 있다.
