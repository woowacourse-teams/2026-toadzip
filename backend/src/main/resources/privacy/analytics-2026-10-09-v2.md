# 서비스 개선을 위한 이용 정보 수집 (선택)

더 나은 서비스 경험을 위해 화면 조회·기능 사용 정보를 통계적으로 분석합니다.  
**이름·이메일·회원 ID와 연결하지 않습니다.**

동의하지 않아도 서비스를 이용할 수 있습니다. 동의 후부터 수집하며, 동의 전의 행동을 모아 두었다가 전송하지 않습니다.

## 수집 목적과 항목

서비스 이용 현황을 파악하고 사용성·기능을 개선하기 위해 화면 조회, 검색·필터·단지·공고·알림 기능의 사용 기록, 공개 단지·공고 번호, 접속 시각, 브라우저·기기 정보와 분석용 식별자를 처리합니다. 검색어 원문, 이름, 이메일, 소셜 계정·회원 식별자, 입력 내용은 분석 도구로 보내지 않습니다. 알림 설정 등 회원 업무 정보와 분석 자료를 연결하지 않습니다.

## 이용하는 분석 도구

Google Analytics 4와 PostHog를 사용합니다. Google Analytics는 쿠키의 무작위 client ID로 브라우저를 구분합니다. PostHog는 메모리의 무작위 distinct ID로 현재 실행 중의 행동을 구분하며, 사람 프로필·자동 클릭 수집·세션 녹화를 사용하지 않습니다. 이들 분석용 식별자는 이름을 포함하지 않지만 행동을 연결할 수 있으므로, 개인을 절대로 식별할 수 없는 익명 집계만을 수집한다는 뜻은 아닙니다.

전송 주소에는 검색어·회원정보가 포함된 경로나 쿼리를 넣지 않습니다. 네트워크 통신 과정에서 분석 제공자에게 IP 주소가 전달될 수 있습니다. 광고 개인화와 Google Signals는 사용하지 않고 PostHog의 IP 기반 위치 보강은 요청하지 않습니다.

## 보유와 삭제

분석 도구에 이미 전송된 자료의 삭제는 각 제공자의 보유 설정과 삭제 절차를 따릅니다. 동의 유효기간 180일이 분석 자료의 보유기간을 뜻하지 않으며, 동의 철회나 서비스 DB 삭제만으로 외부 자료가 즉시 삭제되지는 않습니다. 외부 자료의 보유기간·처리 국가·국외이전 조건은 운영 프로젝트에서 확인하여 운영 공개 전에 이 안내에 반영해야 합니다.

## 선택 관리와 철회

허용은 마지막 명시적 선택부터 180일 유지합니다. 회원 거부·철회는 계정이 존재하는 동안, 비회원 선택은 현재 브라우저에서 180일 유지합니다. 선택 시점·안내 버전·변경 순서는 선택을 존중하기 위해 저장하며 행동 분석에 사용하지 않습니다. 선택이 대체·만료·범위 변경으로 효력을 잃은 증빙은 최대 90일 보유합니다.

정보·설정의 분석 설정에서 언제든 거부하거나 철회할 수 있습니다. 철회하면 현재 브라우저의 새 전송을 중지하고 아직 보내지 않은 분석 큐를 폐기합니다. 다른 기기의 선택은 서버 상태를 다시 확인할 때 반영하며 확인 없이 허용을 유지하는 시간은 최대 60초입니다. 거부·철회해도 기본 서비스 이용에 제한이 없습니다.
