# 서비스 개선을 위한 이용 정보 수집 (선택)

더 나은 서비스 경험을 위해 화면 조회·기능 사용 정보를 통계적으로 분석합니다.  
**이름·이메일·회원 ID와 연결하지 않습니다.**

동의하지 않아도 서비스를 이용할 수 있습니다. 동의 후부터 수집하며, 동의 전의 행동을 모아 두었다가 전송하지 않습니다.

## 수집 목적과 항목

서비스 이용 현황을 파악하고 사용성·기능을 개선하기 위해 화면 조회, 검색·필터·단지·공고·알림 기능의 사용 기록, 공개 단지·공고 번호, 접속 시각, 브라우저·기기 정보와 분석용 식별자를 처리합니다. 검색어 원문, 이름, 이메일, 소셜 계정·회원 식별자, 입력 내용은 분석 도구로 보내지 않습니다. 알림 설정 등 회원 업무 정보와 분석 자료를 연결하지 않습니다.

## 이용하는 분석 도구

PostHog를 사용합니다. PostHog는 동의한 브라우저의 무작위 분석 식별자로 재방문과 기능 사용을 구분합니다. 이 식별자는 브라우저의 로컬 저장소에 보관하며, 회원 계정과 연결하지 않습니다. 다른 브라우저나 기기를 동일한 사람으로 합치지 않으며, 사람 프로필·자동 클릭 수집·세션 녹화를 사용하지 않습니다. 이 분석용 식별자는 이름을 포함하지 않지만 행동을 연결할 수 있으므로, 개인을 절대로 식별할 수 없는 익명 집계만을 수집한다는 뜻은 아닙니다.

전송 주소에는 검색어·회원정보가 포함된 경로나 쿼리를 넣지 않습니다. 네트워크 통신 과정에서 분석 제공자에게 IP 주소가 전달될 수 있습니다. PostHog의 IP 기반 위치 보강은 요청하지 않습니다.

## 보유와 삭제

PostHog 분석 식별자는 로컬 저장소에 무작위 값·생성 시각·만료 시각만 저장합니다. 사용기간은 생성부터 최대 180일이며, 현재 분석 동의의 만료가 더 빠르면 그 시각까지만 사용합니다. 재방문·조회·로그인·로그아웃이나 새로운 허용 선택으로 기존 식별자의 기간을 연장하지 않습니다.

동의를 거부·철회하거나 동의 또는 식별자가 만료되면 사용을 중단하고 식별자를 폐기합니다. 처리 범위가 변경되어 재동의가 필요하거나 현재 회원·비회원 범위에 유효한 허용이 없음을 확인한 경우에도 폐기합니다. 일시적인 전송 중단이나 로그인·로그아웃만으로 식별자를 바꾸지는 않지만, 전환 후 유효한 허용을 확인하기 전에는 수집하지 않습니다.

브라우저가 닫혀 있는 동안에는 저장소 삭제 작업을 실행할 수 없습니다. 이 경우 다음 서비스 실행 시 만료된 식별자를 삭제하며, 만료된 식별자를 다시 분석에 사용하지 않습니다.

분석 도구에 이미 전송된 자료의 삭제는 각 제공자의 보유 설정과 삭제 절차를 따릅니다. 동의 유효기간과 브라우저 분석 식별자의 사용기간은 전송된 분석 자료의 보유기간을 뜻하지 않으며, 동의 철회나 서비스 DB 삭제만으로 외부 자료가 즉시 삭제되지는 않습니다.
