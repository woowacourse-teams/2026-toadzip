# 개인정보처리방침

공공주택 복덕방은 아래 목적에 필요한 개인정보를 처리합니다.

## 회원 정보

소셜 로그인 제공자와 제공자별 식별자, 내부 회원 ID 및 가입 시각을 계정 식별과 로그인 제공에 사용합니다. 소셜 로그인 제공자가 전달한 회원 이메일은 관리자의 회원 조회·검색에 사용하며, 실제 이메일 알림은 발송하지 않습니다. 회원 정보는 계정을 유지하며 해당 목적에 필요한 동안 보유하고, 회원 탈퇴 또는 처리 목적 종료 시 삭제합니다. 로그인은 분석 수집 동의를 의미하지 않습니다.

## 알림 설정

회원 ID, 관심 단지·공고·지역, 신청·취소 시각 및 적용 안내 버전을 사용해 요청한 알림 설정을 저장합니다. 실제 알림 전달 기능은 준비 중입니다. 신청은 이메일 수신이나 마케팅 동의가 아닙니다. 활성 설정은 신청부터 12개월 유지합니다. 취소·만료된 설정은 실제 비활성 시점부터 90일 이내 삭제하고, 신청·취소 업무 기록은 발생부터 90일 보유합니다. 이미 활성인 설정을 다시 조회하거나 신청해도 기간을 연장하지 않습니다.

## 분석 선택 관리

회원은 계정별로, 비회원은 현재 브라우저별로 선택을 관리합니다. 선택 상태, 적용 안내 버전, 서버 처리 시각, 명령 식별자 및 변경 순서를 저장하며 비회원 동의 쿠키 토큰은 해시로 저장합니다. 이러한 관리 정보는 행동 분석 식별자와 결합하지 않습니다. 회원의 허용과 비회원의 선택은 마지막 명시적 선택부터 180일 유지합니다. 회원의 거부·철회는 탈퇴할 때까지 유지합니다. 유효한 선택 증빙은 선택이 유지되는 동안, 대체·만료·범위 변경으로 효력을 잃은 증빙은 그 시점부터 최대 90일 보유합니다. 선택하지 않은 비회원 준비 기록은 24시간 후 삭제합니다.

## 이용 정보 분석

유효한 선택적 동의 후 Google Analytics 4와 PostHog를 사용해 화면 조회·기능 사용 정보를 통계적으로 분석합니다. 이름·이메일·회원 ID, 검색어 원문과 입력 내용을 분석 도구로 보내거나 분석용 식별자와 연결하지 않습니다. 자동 클릭 수집, 사람 프로필과 세션 녹화는 사용하지 않습니다. 분석용 무작위 식별자는 행동을 연결할 수 있어 완전히 익명인 집계와는 다릅니다. 분석 제공자에게 통신 과정의 IP 주소가 전달될 수 있습니다.

미선택·거부·동의 만료에는 수집하지 않으며, 정보·설정의 분석 설정에서 철회하면 현재 브라우저의 새 전송을 즉시 중지하고 대기 큐를 폐기합니다. 동의 전에 발생한 행동은 나중에 전송하지 않습니다. 이미 전송된 자료는 제공자의 보유 설정과 삭제 절차를 따르며, 철회만으로 소급 삭제되지는 않습니다. 분석 자료의 보유기간·처리 국가·국외이전 조건은 운영 프로젝트에서 확인하여 운영 공개 전에 안내에 반영해야 합니다.

## 쿠키와 브라우저 저장소

로그인 세션과 요청 보호(CSRF)를 위한 쿠키를 사용합니다. 비회원 분석 선택을 복원하기 위한 HttpOnly 동의 쿠키는 선택부터 180일, 선택 준비만 한 경우 24시간 유지하며 방문으로 기간을 연장하지 않습니다. 브라우저에는 거부·철회 저장 재시도에 필요한 최소 정보를 최대 180일 저장할 수 있습니다. 유효한 분석 동의 후에만 GA의 분석 쿠키를 사용하며 중지 시 제거합니다. PostHog 분석 식별자는 메모리에서 사용하고 중지 시 폐기합니다. 분석 거부는 로그인·알림 설정 이용에 영향을 주지 않습니다.
