- 실행: [환경 설정](../docs/SETUP.md)
- 서비스 기능·운영: [docs](../docs/README.md)
- 백엔드 개발 기준: [하네스 지도](docs/README.md), [코드 컨벤션](CODE_CONVENTION.md)
- 에이전트·검증·Git: [작업 지침](AGENTS.md), [기여 규칙](../CONTRIBUTING.md)

코드는 `src/main/java`, 설정·마이그레이션은 `src/main/resources`, 테스트는 `src/test`에 있다.
