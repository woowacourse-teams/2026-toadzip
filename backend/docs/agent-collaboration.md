# Backend Agent Collaboration

## 역할 지도

| 역할 | 책임 | 쓰기 권한 |
|---|---|---|
| `backend_explorer` | 실행 흐름과 영향 범위 조사 | 없음 |
| `backend_architect` | 모듈·API·트랜잭션 경계 검토 | 없음 |
| `backend_reviewer` | 정확성·회귀·보안 독립 검토 | 없음 |

역할 정의의 실행 원본은 `.codex/agents/*.toml`이다.

## 위임 조건

- 메인 에이전트가 요구사항, 구현, 파일 소유권, 통합과 최종 검증을 책임진다.
- 서브에이전트에는 독립적인 조사, 설계 검토와 리뷰만 위임한다.
- 서브에이전트는 읽기 전용으로 사용하며 구현 파일을 수정하지 않는다.
- 같은 파일, 공용 설정, 마이그레이션 번호를 동시에 수정하지 않는다.
- 순차 의존성이 있으면 앞 작업의 계약이 확정된 뒤 다음 작업을 시작한다.

## 위임 계약

```text
Goal: 달성할 단일 결과
Scope: 읽거나 수정할 정확한 경로와 소유권
Inputs: 결정된 계약, 근거, 실패 증상
Constraints: 아키텍처, 안전, 금지 작업
Deliverable: 기대 변경 또는 근거 요약
Done: 실행할 검증과 기대 결과
```

## 역할별 완료

- Explorer: 결론마다 파일·심볼 근거와 미확인 사항을 반환한다.
- Architect: 선택지, 추천 경계, 트레이드오프와 자동 검증법을 반환한다.
- Reviewer: 심각도순 발견, 재현법과 안전한 수정 경로를 반환한다.
- 서브에이전트는 전체 작업의 완료를 선언하지 않는다.

## 통합

1. 메인이 결과를 Goal과 Done에 대조한다.
2. 공유 인터페이스와 중복 구현을 확인한다.
3. 최종 작업 트리에서 검증을 다시 실행한다.
4. 독립 리뷰의 blocker를 해결하거나 근거 있게 기각한다.
5. 미검증 항목과 잔여 위험을 사용자에게 보고한다.
